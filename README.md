# Blind Spot

**Blind Spot** is an infiltration prototype developed in Unity 6 whose primary goal is to demonstrate an AI system based on a **Finite State Machine (FSM)**, perception, and navigation.

The AI is the core of the project. The gameplay exists to put the player in situations where they can observe and trigger different enemy behaviors.

- Assets and systems that **I did not develop myself** can be found in the **Assets/ThirdParty/** folder.

- Assets and systems that **I developed myself** can be found in the **Assets/_MFA/** folder.
